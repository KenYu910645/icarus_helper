# 隨附授權原文

這個目錄保留執行元件的上游授權、著作權聲明與來源資訊，不替本專案自有程式碼新增授權。

- `Python-3.12.10-LICENSE.txt`、`PyInstaller-6.21.0-COPYING.txt` 等檔案由本次使用的安裝套件原樣複製。
- `Qt-6.11.1/` 保存 Qt 官方 `v6.11.1` 來源中的授權及第三方 attribution。目錄結構沿用上游，`attributions.json` 是便於查閱的合併清單；上游列出的選用／其他平台元件不代表全部隨 APP 啟動。
- `OpenSSL-3.0.16-LICENSE.txt` 來自 OpenSSL 官方對應版本；Mesa／LLVM 文字來自 Qt 6.11 官方 attribution 頁。
- `MSVC-Runtime-2015-2022-LICENSE.txt` 由 Microsoft 官方授權 DOCX 的全部文件段落轉為 UTF-8 文字，保留原文；原 DOCX 連結記在 `sources.json`。
- `installed-package-metadata.json` 記錄實際建置套件的版本及原始 License metadata。
- `sources.json` 記錄所取回原文的來源、大小與 SHA-256。它不包含使用者路徑、遊戲存檔或帳號。

對應元件、來源下載及遊戲／社群素材說明見專案根目錄的 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
