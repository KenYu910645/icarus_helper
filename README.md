# ICARUS Helper

繁體中文 Windows 桌面助手，唯讀追蹤本機／主機世界存檔。地圖和任務使用同一次通過完整性驗證的快照，遊戲存檔改變後自動更新。

## 下載 Windows APP

前往 [GitHub Releases](https://github.com/KenYu910645/icarus_helper/releases/latest)，下載 `ICARUS-Helper-<版本>-Windows-x64.zip`。完整解壓縮後開啟 `ICARUS Helper.exe`，並保留 `_internal` 資料夾。不需要安裝 Python，也不需要另外下載圖資；GitHub 的 `Source code.zip` 是開發用原始碼，請選 Windows 成品 ZIP。

第一次開啟預設顯示 **Prometheus 共用地圖與「我們家」**，不要求本機先有遊戲存檔。共用地圖會標示「未連接主機存檔」；基地座標是隨附的共用位置，可在地圖右鍵管理，與實際世界的基地設定分開保存。切換至自己的世界後，APP 會記住選擇。

共用地圖只提供靜態圖資與任務攻略預覽，不含主機私人存檔、帳號、玩家位置、庫存或任務進度；剩餘礦量與鑽機狀態維持未知。需要實際狀態時，請按「選擇主機存檔…」指定有效來源。APP 不會跨電腦自動同步，一次複製的檔案只代表那次存檔。

目前發佈 Windows x64 可攜版。主要支援 Prometheus，其他地圖覆蓋較少；不同電腦環境仍可能需要相容性確認。第三方素材與套件說明見 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，目前未另外授予本專案程式碼開源授權。

## 開啟與使用

1. 開啟桌面「ICARUS Helper」，或執行 `dist/ICARUS Helper/ICARUS Helper.exe`。從原始碼啟動可使用 `launch.ps1`。
2. 第一次開啟會選擇共用地圖。要追蹤自己的世界，請在上方切換本機世界，或按「選擇主機存檔」選取主機的唯讀副本／來源；本機舊副本不會自動變成最新主機資料。
3. 在地圖按右鍵，選「新增基地（此處）」設定「我們家」；也可從右鍵選單選部署物聚集候選。右鍵點基地可編輯、刪除或設為主要基地；空白處可將目前基地移到該處，並可切換已保存的基地。設定按世界保存。
4. 地圖滾輪縮放、拖曳平移；右鍵選單提供「顯示全圖」及「定位到主要基地」。右側可以篩選礦種、圖層及鑽機狀態，直接點圖標查看明細。
5. 切換「任務地圖與攻略」，閱讀攻略與攜帶物品表，並查看各階段的執行地點。點選階段可定位；候選位置使用問號虛線，位置尚未決定的階段會列在下方。
6. 切換「家中物資」，查看目前基地周圍容器與設備的存檔物資。預設水平半徑 100 m，可調整範圍及物資類別。金、銅、鐵等材質各為一組，橙色是原礦、藍綠色是錠；下方可查物品數量與所在容器。圖表依各組實際件數合計由多到少排列，明細依單項數量由多到少排列；未知數量放在最後。
7. 切換「馴養動物」，依飼養者分欄查看動物卡片；原生動物圖示代表種類，卡片顯示等級與生命、食物、水、氧氣、耐力及經驗狀態條。點選卡片可看鞍具、背包與重型貨物的物品圖示及數量，停留圖示或展開「物品名稱、數量與槽位」可核對明細；完整狀態數值及血統、遺傳、天賦也可展開。預設列全部玩家馴養動物，可搜尋或篩選家附近、離家及位置未知。

馴養動物地圖與卡片使用同一次存檔，標記保留原始位置，支援滾輪縮放、拖曳平移、全圖、全部動物及定位基地。點選地圖動物會選取對應卡片；點卡片的「⌖」可在地圖定位，搜尋與範圍篩選也會同步套用。位置未知的動物保留卡片，不捏造地圖座標；共用地圖未連接主機存檔時不顯示私人動物。

經驗條依已驗證的種類經驗曲線顯示本級升級進度。食物、水分與已驗證物種的氧氣條使用遊戲配置容量。遊戲開啟且身分核對成功時，生命及適用耐力取自遊戲介面相同來源，成對顯示目前值／真正上限，包含已套用的飼養者及臨時效果；滑鼠停留可查看讀取時間。無遊戲來源時才用明示範圍的存檔計算：`*`為已計飼養者持續加成、`≈`為未含完整飼養者加成的個體基準。牛氧氣／耐力仍未驗證；未知斜紋與問號不當成零或滿條。飼養者只顯示角色名稱，同名不同角色仍分欄；無法確認主人則列入未知欄。

助手的圖示保留金色ICARUS標誌，右下角加上綠色「H」角標，方便與遊戲區別。視窗、工作列及桌面捷徑使用同一款助手圖示。

馴養動物的物種名稱使用遊戲原生英文，例如 Terrenus、Moa、Buffalo、Ubis、Cow；動物自訂名稱與其他繁中介面保留。搜尋仍可輸入中文物種別名。

物資整理成五大類：「礦石、金屬與燃料」「材料、零件與建材」「食物與醫療補給」「工具、裝備與彈藥」「其他物品」。金屬原礦、錠及礦物燃料放在同一頁分色比較；項目較多時可水平捲動圖表。未辨識物品有資料時另列。

物品名稱旁附遊戲原生圖示，圖表各柱下方也顯示對應物品；原礦和錠使用各自的圖片。滑鼠移到圖示可查看物品與數量。圖示隨APP封裝，執行時不需連網或讀取遊戲安裝檔；缺圖以問號表示並保留名稱。小視窗可捲動查看圖示與座標軸標籤。

地圖預設顯示地穴、深層礦床、噴泉、特殊資源、石油、鑽機、玩家與候選點；隱藏一般礦石等密集圖層。後續勾選會保存，也可按「還原預設圖層」。地穴使用洞口圖標，一般礦與深層礦床使用遊戲原生礦物圖示；問號虛線是候選，已放鑽機的礦床有紅色外圈、紅色礦名底板及綠色鑽機角標。所有標記直接放在實際位置，允許重疊，不加引線。已設定家時，開啟世界會先定位家附近；世界邊緣只裁切圖標的溢出部分，不移動座標。

異質圖層與未確認的異質候選點使用遊戲原生異質類別圖；候選以角落的小問號及虛線框表示。類別圖不代表已確認礦種或生成狀態，已確認的紅異質與鈾仍使用各自圖片。

資源地圖的所有圖示下方都有中文名稱，包含異質、噴泉、石油、水源、植物及部署物；縮小地圖後仍顯示。可以直接點選圖示或下方名稱查看明細。

Prometheus 預設使用包含 Null Sector 的完整地形底圖，南方冰原與東南灰燼地形也可縮放查看；資源、任務與動物地圖共用這張底圖。它是助手提供的地形參考，不代表遊戲內地圖已解鎖，也不保證標記間有可通行路線。完整圖隨 APP 封裝，更新後不需手動清除舊快取。

世界／地圖、所選基地與存檔時間放在最上方資訊列的左側，旁邊是縮短的世界下拉選單。小視窗可折行，滑鼠停留可看完整來源／更新時間。「重新整理」按鈕會顯示讀取／重試狀態。檔案尚在寫入或損毀時，保留上次成功畫面並標示過期。大標題／logo列、統計卡、綠色說明列、地圖頂部基地工具列、底部資源表及狀態列已依使用者要求移除。

## 現有功能與資料範圍

- Prometheus：目前安裝版本的 64 個生成區塊、64 個地表區塊，24,159 個原始一般礦石生成點、221 個地穴入口，加上社群地穴編號及候選資源。合併存檔時以精確 ActorPath 為優先，不把生成點數當作剩餘礦量。
- 樹木、植物與地表資源以生成分布區域呈現，水源以遊戲資產錨點呈現。只有唯一對應生成描述與存檔破壞索引時，才提供未列為已破壞的實例數；這不是最終物品產量。
- 深層礦床顯示礦種、剩餘欄位與鑽機狀態。鑽機優先以 UID 明確配對，只有無明確關聯且三維雙向唯一時才推定；設備放置與正在運轉分開顯示。
- 任務目錄含目前版本的 128 個操作與 11 種 SMPL3 類型。Prometheus 的 24 個操作有專屬繁中攻略；目前進度、前置與 C0NT4CT 模組由所選世界存檔判定。
- 任務地圖階段使用與資源地圖、物資統計相同的主要基地計算水平直線距離。任務地點尚未確定會保留待定位；候選距離標明候選，不能用來當作已確認的距離排序。
- 家中物資由目前有效快照的已部署容器／設備讀取，使用安裝版本的 3,037 個物品定義。原礦、錠與加工坯分色、分件數，不換算熔煉比例；每次有效存檔及切換基地後背景更新。
- 馴養動物由明確馴服／主人證據篩選，依飼養者分欄，動物與物品圖示、狀態條及位置地圖整合在同一頁。目前 241 個種類定義中 219 個具有原生圖，另 22 個保留問號；原生圖是種類／圖鑑群組代表，不表示該隻動物的毛色、性別或外觀變異。
- Olympus 有底圖、地穴目錄及本機存檔校準；Styx 有底圖／社群目錄，缺乏校準時不套用格位或合併候選點。其他地圖的一般礦全圖還原與專屬攻略尚未完成，介面來源與覆蓋清單會明示。

## 資料限制

- 存檔不是全世界每個物件的完整即時清單。缺少採集記錄不能當作未採集，缺少數量不能當作零，負值也不自動視為無限。
- 一般礦體的資源計數差值標示為基礎資源估計，並非保證物品產量。部分動態特殊礦點缺少靜態資產關聯時，礦種仍顯示未知。
- 社群地圖點是候選，是否在本世界生成依存檔確認；鄰近地穴關聯只有距離證據時標示推定。
- 玩家位置是最後存檔位置。任務記錄點不是已驗證的目標入口；所有顯示距離均為水平直線距離。
- 動物地圖位置代表有效存檔。遊戲執行且世界／動物識別完全吻合時，生命與適用的耐力直接唯讀取得遊戲介面使用的目前值與上限，包含遊戲已套用的飼養者及臨時效果；動物頁開啟時每30秒背景更新並標示讀取時間。未執行、不同世界或無法可靠核對時使用存檔來源：`*`是已計飼養者的持續上限，`≈`是飼養者資料未完整的個體基準。食物、水分與已支援氧氣容量依現版資料計算。牛的氧氣／耐力及乳量容量仍未知；缺值不當作零。隊友資料可透過「飼養者資料…」連接Characters、Profile與BestiaryData唯讀備份，按世界保存設定；不以同名角色配對。
- SMPL3 的當下隨機任務抽選、DLC 使用權與角色科技尚未全部還原，必要條件缺失時顯示待確認。物資統計尚未用於自動勾選任務準備清單。
- 家中物資以水平半徑選取容器，未判定所有權、樓層或可存取性。排除玩家／坐騎背包、地面物品、全域重複物品池、已穿戴裝備與設備升級槽；未展開存放裝備內的配件與袋內物品。數量缺失或衝突顯示未知，不當作零。
- 未解碼的非核心 UE 屬性會列入警告；核心部署資料不足時不宣稱未放鑽機。版本不符時不繼續宣稱舊礦種規則或任務可接判定有效。
- 完整來源、版本、校準與覆蓋狀態可在 APP 按「資料覆蓋與來源」查看；資料建置細節見 `DATA_SOURCES.md`。

## 設定與安全

APP 不啟動、不控制遊戲，也不修改原始存檔或遊戲安裝檔。基地、所選世界與圖層設定固定保存於 `%USERPROFILE%/.icarus-helper/settings.json`，不同安裝位置與啟動方式共用同一份設定。首次更新會從舊 LocalAppData 與 Codex LocalCache 設定復原基地，保留原檔及 `legacy-backups` 備份；之後不再重新匯入，避免讓已刪除的基地復活。同時開啟多個視窗時，儲存僅合併本視窗的變更。

最後有效存檔副本、地圖快取與本機診斷記錄仍存於 `%LOCALAPPDATA%/IcarusHelper/`。「資料覆蓋與來源」可查看實際設定檔位置。專案不包含完整私人存檔或帳號憑證。測試只使用合成存檔或唯讀快照；沒有在原世界進行放置、採礦或接任務操作。

## 開發與建置

已驗證環境：Windows、Python 3.12、PySide6 6.11.1、PyInstaller 6.21.0。程式可處理 Unicode／OneDrive 路徑。

```powershell
python -m pip install -r requirements-dev.txt
python main.py
python -m pytest -q
```

原始碼已附 `icarus_helper/atlas/26313227/` 精簡圖資，clone 後不需要私人快取就能啟動與建置目前版本；要重新產生圖資，請依 `DATA_SOURCES.md` 與 `tools/README.md` 設定自己的合法遊戲來源。封裝只收集執行需要的精簡 JSON 與底圖，不收集大型原始解包資產：

```powershell
powershell -NoProfile -File tools/build_app.ps1 -Shortcut
```

輸出為 `dist/ICARUS Helper/`；必須保留整個資料夾。封裝內有精簡地圖資料，執行時不依賴舊分析資料夾、Python、repak 或 UAssetAPI。

建置會隔離原生工具搜尋路徑、檢查Qt所需ICU匯出，並直接執行封裝EXE，以獨立空設定驗證共用地圖／基地、底圖及物品圖示。需要檢查真實世界整合時，可另以 `--self-test-report artifacts/packaged-startup.json --self-test-reference-settings <自己的設定檔>` 唯讀複製來源與基地設定到隔離暫存設定，再驗證實際物資；不修改原基地。啟動診斷會在載入Qt前開始寫入APP記錄。

公開成品可使用獨立輸出目錄，保留正在使用的舊版 APP：

```powershell
powershell -NoProfile -File tools/build_app.ps1 -OutputRoot dist/releases/v0.2.1
python tools/package_release.py --bundle "dist/releases/v0.2.1/ICARUS Helper" --output releases/v0.2.1 --version v0.2.1
```

目前建置必須通過沒有使用者設定的共用地圖／基地首次啟動驗收，結果為 `artifacts/packaged-shared-startup.json`；個人世界整合可另用 `--self-test-reference-settings` 驗證，不會隨 Release 公開。封裝排除未使用的 Qt PDF／Virtual Keyboard／QML／Quick 元件，移除前先檢查剩餘原生檔案沒有依賴。ZIP 隨附第三方授權、逐檔 SHA-256 manifest，旁邊產生 `SHA256SUMS.txt`。

`artifacts/`、`build/`、`dist/`、`releases/` 與使用者設定／存檔快照不提交至 Git；成品 ZIP 透過 GitHub Releases 提供。

介面離線驗證（使用獨立設定，唯讀實際存檔）：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
python tools/verify_desktop.py
```

這會產生 `artifacts/ui/verification.json` 與版面圖，驗證縮放、平移、篩選、基地隔離／保存及任務攻略。加上 `--reference-settings "$env:USERPROFILE/.icarus-helper/settings.json"` 可唯讀複製目前基地設定，另驗證家中物資；工具只修改自己的暫存設定。它是 Qt 元件測試，不是遊戲內操作證明。

馴養動物卡片與地圖另可執行 `python tools/verify_animal_board.py`，工具從目前已選來源建立隔離設定，唯讀檢查分欄、原生圖、定位、篩選及小視窗，輸出到 `artifacts/animals-refined-20261102/`。此驗證使用真實存檔的 Qt 元件，與 Windows 桌面滑鼠操作及遊戲內操作驗證分開；來源需有可辨識動物及離家案例，細節見 `tools/README.md`。

動物容量的唯讀驗證使用 `python tools/verify_animal_capacities.py`，另存當次快照、精確補給容量、個體重建值與未知欄位的核對結果。原生計算規則已有470例離線仿真證據；這是以合成數值執行有限的原生函式位元組，沒有啟動遊戲，也不能代稱真實存檔整合、封裝或Windows桌面操作已通過。各類驗收分開記錄。

## 模組

- `models.py`：UI 無關的世界／資源模型。
- `saves.py`：發現世界、穩定唯讀快照、封裝／UE 屬性解析、動態資源與鑽機關聯。
- `catalog.py`：靜態地圖目錄、礦種生成規則、動態合併、植被分布及資料覆蓋。
- `missions.py`、`data/missions.json`：任務狀態、推薦、版本檢查與攻略。
- `controller.py`：檔案監看、去抖動、背景工作、失敗恢復及世界切換隔離。
- `map_widget.py`、`ui.py`：桌面地圖、資源明細、右鍵基地與任務操作。
- `inventory.py`、`data/inventory_items.json`：同快照的基地容器、物品分類與數量統計。
- `inventory_view.py`：背景統計、分類分色長條圖與容器明細。
- `item_icons.py`、`data/item_icons.json`、`assets/items/`：物品原生圖示對照、透明縮圖及缺圖備援。
- `animals.py`、`data/animal_catalog.json`：馴養證據、逐隻狀態與背包、匿名主人分組鍵及已驗證的等級／經驗進度。
- `animal_capacities.py`、`data/animal_capacities.json`、`data/animal_capacity_effects.json`：版本綁定的物種容量與加成來源、精確補給容量及明示缺口的生命／耐力個體重建。
- `animals_view.py`、`animal_widgets.py`、`animal_map.py`：依飼養者分欄的圖示卡片、狀態條、物品圖示及同快照動物地圖。
- `animal_icons.py`、`data/animal_icons.json`、`assets/animals/`：原生圖鑑種類圖、來源對照及問號備援。
- `settings.py`：APP 自有設定與原子儲存。

修改程式前閱讀 `AGENTS.md`，修改後同步檢查該文件與實際支援狀態。
